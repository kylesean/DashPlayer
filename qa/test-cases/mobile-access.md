# 手机访问

用例文件：`qa/specs/settings/mobile-access-settings.spec.ts`（本页所有自动化用例都在这里）

规范与状态含义见 [README.md](./README.md)。

## 访问令牌

这一页启用后会在局域网可达的地址上起一个 HTTP 服务，页面上给出可直接粘贴到手机浏览器的访问地址。
地址里带一枚访问令牌：没有令牌的设备打不开页面，服务端的接口（观看记录、字幕、视频流、翻译）
也都要求带上它。用例直接用 HTTP 请求去戳服务，断言的是「真的进不去 / 真的进得去」，
而不是界面上的文案。

- 该看到：启用开关与端口输入框；服务运行时展示形如 `http://<局域网地址>:<端口>/?t=<令牌>` 的访问地址；
  地址区块右侧有「刷新」与「重新生成令牌」两个操作；状态点显示「运行中」。
- 用例：**[SET-MOB-01]** 开启后访问地址带令牌，没有令牌的请求被拒绝
- 用例：**[SET-MOB-02]** 重新生成令牌后旧地址立刻失效，新地址可用
- 用例：**[SET-MOB-03]** 关闭后不再展示访问地址

## 还没覆盖的场景

### 端口冲突

- 现状：端口被别的进程占用时，服务起不来，页面显示「启动失败」与原因。
- 编号：**[SET-MOB-04]**（手动）

### 真实手机访问

- 现状：用例是在测试机上用 HTTP 请求验证的，没有真的拿手机连一次。
- 编号：**[SET-MOB-05]**（手动）
