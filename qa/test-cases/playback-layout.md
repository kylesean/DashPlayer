# 播放页分栏复位

用例文件：`qa/specs/player/layout-split-reset.spec.ts`（本页所有自动化用例都在这里）

规范与状态含义见 [README.md](./README.md)。

分栏比例存在 localStorage，用户拖过一次之后就会一直沿用。双击分隔条是唯一的「回到默认」
出口，所以它必须对**任意**一条分隔条都生效——此前上下与左右各管一轴，用户拖动过其中一组、
却双击了另一组，看起来就像复位完全没生效。

## 双击任一分隔条

两组比例都被用户改过之后，双击其中任意一条，左右与上下必须同时回到默认值。

- 该看到：左右回到 75/25；上下回到当前字号与整句模式对应的默认比例（25%~32%），且两段之和为 100。
- 用例：**[SET-PLY-02]** 双击任一分隔条都会同时复位两组比例

## 文稿面板收起时双击主字幕分隔条

用户收起字幕文稿后，左右分隔条从 DOM 里消失，只剩上下一条。此时双击它不能因为
「另一组 pane 不存在」而抛错或静默失效。

- 该看到：上下比例回到默认区间，页面无报错。
- 用例：**[SET-PLY-03]** 字幕文稿收起后双击主字幕分隔条仍能复位且不抛错

## 大字号下的默认分栏

字号调到大号后，默认上下比例要跟着放大，否则双语字幕会被挤出面板；同时长句允许温和缩放，
但不能低于可读下限。

- 该看到：复位后字幕段不低于 28%；主字幕内容完整落在面板内（不出现纵向溢出）；
  `--sub-scale` 落在 0.85~1 之间。
- 用例：**[SET-PLY-04]** 大字号下复位后双语字幕仍完整落在默认面板内
