# YouTube 链接导入

用例文件：`qa/specs/settings/youtube-import.spec.ts`（本轮为手动用例，尚未自动化）

本页场景依赖真实 YouTube 网络与 yt-dlp 下载，无法在 CI 中稳定复现，因此全部登记为手动；
ID 保留给后续自动化补齐。

## 成功导入单条视频

- 前置：功能开关已开启，网络可访问 YouTube。
- 操作：粘贴一个带英文字幕的 YouTube 链接，点击「下载并导入」。
- 该看到：任务行显示视频身份与「连接 YouTube… → 下载视频 xx% → 整理文件…」等阶段；完成后出现「去播放」，点击进入播放页，字幕已挂载。
- 编号：**[SET-YTI-01]**（手动）

## 下载失败

- 操作：粘贴一个受限/已删除/私享视频链接并发起导入。
- 该看到：任务行出现红色 Banner，标题为友好摘要（如「视频不可用、已删除或为私享视频」），展开后可看到原始技术详情，并提供「重试」「复制链接」。
- 编号：**[SET-YTI-02]**（手动）

## 取消进行中的任务

- 操作：发起导入后，在「排队中」或「下载中」点击「取消」。
- 该看到：取消按钮出现 loading；取消成功后任务行变为「已取消」，不会出现「去播放」；取消完成后不再占用同一视频的导入锁。
- 编号：**[SET-YTI-03]**（手动）

## 连续批量导入

- 操作：连续粘贴两个不同链接并分别提交。
- 该看到：两个任务行同时存在且各自更新；任一完成只出现该行的「去播放」，不会自动跳转、不打断下一条输入；关闭再打开弹窗后，进行中的任务仍在。
- 编号：**[SET-YTI-04]**（手动）

## 重复提交同一链接

- 操作：在同一链接的任务尚未结束时再次粘贴并提交。
- 该看到：主按钮在提交期间为 loading/禁用；即使触发提交也提示「该视频已在导入中，请勿重复提交」，不会新增第二个任务行。
- 编号：**[SET-YTI-05]**（手动）

## 关闭弹窗后的进度与结果提示

- 操作：发起导入后立即关闭弹窗，等待任务结束。
- 该看到：顶部入口/侧栏显示「导入中 n」；成功或失败时出现 toast；重新打开弹窗仍能看到进行中的任务（已完成任务在关闭时已清理）。
- 编号：**[SET-YTI-06]**（手动）

## 非法链接行内校验

- 操作：输入 B 站链接、非 YouTube 域名或残缺 URL。
- 该看到：输入框下方出现红色「请输入有效的 YouTube 视频链接（youtube.com 或 youtu.be）」，主按钮禁用；粘贴合法 YouTube 链接后错误消失、按钮恢复可用。
- 编号：**[SET-YTI-07]**（手动）

## 首页 Hero 与弹窗共享状态

- 前置：观看历史为空，首页显示 YouTube 主视觉。
- 操作：在 Hero 发起导入，再通过顶部按钮打开弹窗。
- 该看到：弹窗内显示 Hero 发起的同一任务与相同进度；两处输入框草稿一致；任一入口提交后另一入口同步清空。
- 编号：**[SET-YTI-08]**（手动）
