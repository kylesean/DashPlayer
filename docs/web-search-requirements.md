# Refrain 整句学习 AI 搭档 — 联网搜索需求文档

> 状态：**需求规划（暂不实施）**  
> 适用模块：整句学习（AI 精读搭档 / `StudyCopilotPane`）与 AI 设置页

---

## 1. 背景与目标

Refrain 的整句学习目前已具备「围绕当前台词、前后文及全片字幕」的本地闭环检索能力（`search_subtitles` 工具）。但在真实语言学习过程中，仅靠视频内嵌字幕和词典无法回答以下问题：

- 台词里的文化典故、影视/历史/流行梗（slang、idiom 出处、作品彩蛋）；
- 专有名词（人名、品牌、地名、机构缩写）的背景含义；
- 易混表达在真实英语语料中的最新地道用法或语域对比；
- 用户明确要求核实外部事实或最新解释的问题（例如「查一下这个表达在美剧里常怎么用」）。

**目标**：在不破坏现有本地隐私体验和教学交互节奏的前提下，为 AI 精读搭档增加**跨模型兼容、用户可控、可引用溯源**的按需联网检索能力。

---

## 2. 核心用户场景

| 场景 | 用户问题示例 | 预期行为 |
| --- | --- | --- |
| 文化梗 / 习语出处 | “这句里的 *jump the shark* 典故是什么？” | 触发 `web_search`，返回起源说明与来源链接 |
| 专有名词背景 | “他说的这个机构/人名是指谁？” | 先看字幕上下文；不足以解释时触发 `web_search` |
| 用法与语域核实 | “现在日常口语还常用这个词吗？” | 结合近期语料讨论，给出语域判断与出处 |
| 剧情内回溯（**不联网**） | “前面哪一句铺垫过这个矛盾？” | 优先且仅调用本地 `search_subtitles`，禁止无谓联网 |

## 3. 技术方案设计

### 3.1 工具抽象层（Provider-Agnostic）

不使用某家模型厂商专有的私有 Search 参数，而是基于 Vercel AI SDK 的统一 `tools` 机制实现标准化工具，保证 OpenAI / Anthropic / Google / DeepSeek / 兼容 OpenAI 协议的模型均可一致工作：

1. **`web_search`**
   - **入参**：`query: string`（检索关键词）、`maxResults?: number`（默认 5，上限 8）。
   - **出参**：结构化条目数组 `Array<{ title, url, snippet, publishedAt? }>`。
   - **职责**：由主进程执行 HTTP 检索（自动复用系统代理设置），屏蔽各搜索源差异。

2. **`web_fetch`（二期增强 / 按需精读）**
   - **入参**：`url: string`。
   - **安全校验**：仅放行 `http:` / `https:`；禁止访问内网 IP / loopback / 本地文件协议；响应体截断上限（例如纯文本 <= 12,000 字符）。
   - **职责**：当搜索摘要不足时提取正文纯文本给模型总结。

### 3.2 搜索数据源支持

设置页支持选择以下至少一类搜索接入方式：

- **Tavily Search API**：针对 LLM/RAG 优化的干净摘要与相关性排序，接入最简单；
- **Serper（Google Search API）/ Brave Search API**：高覆盖度的通用网页检索；
- **DuckDuckGo / 自建 SearXNG（可选免 Key 备选）**：适合不想额外申请搜索 Key 的用户，但需提示稳定性与限流风险。

### 3.3 聊天流事件与工具生命周期

复用现有 `ChatStreamEvent` 的 `tool-call` 与 `tool-result` 通道：

- 工具名称：`web_search`（可选 `web_fetch`）；
- 流式过程中实时展示检索状态（「正在联网检索：`<query>`」）；
- 若检索失败（超时、Key 无效、网络受限），返回结构化 `{ error, retryable }` 给模型，由模型如实告知用户检索失败并基于已知知识谨慎作答，不得编造来源链接。

## 4. 设置与隐私控制

### 4.1 开关分层

1. **全局设置（「AI 模型与服务」设置页）**
   - 「允许 AI 联网搜索」总开关（默认关闭或按搜索源配置就绪情况启用）；
   - 搜索供应商选择与 API Key 配置（复用现有密钥存储与代理规则）。
2. **会话级快捷开关（整句学习输入框工具栏）**
   - 提供轻量级联网切换按钮（Globe 图标）：用户可针对当前对话临时开启/关闭联网；
   - 未配置可用搜索源时，点击开关直接引导至设置页。

### 4.2 隐私边界

- 联网请求**只发送模型提炼后的检索 query**；
- 严禁把本地媒体路径、文件哈希、整部剧完整字幕或用户个人学习笔记发送给第三方搜索服务。

---

## 5. 提示词与模型兼容性

- **Prompt 边界约束**：在 System Prompt 中明确规定：
  - 涉及「片内剧情、人物关系、前后句对照」问题，优先调用本地 `search_subtitles`；
  - 仅在需要外部世界知识、文化典故、专有名词或用户显式要求查询外部信息时调用 `web_search`。
- **小模型与本地模型降级**：
  - 对不支持 Tool Calling 的本地模型（或未开启搜索开关时），不向请求注入 `web_search` tool；
  - 若当前选中模型不具备稳定的工具调用能力，界面提示切换至支持 Tool Calling 的云端模型以启用联网功能。

---

## 6. 前端交互与引用展示

- **工具调用卡片**：复用 `StudyCopilotPane` 内现有 Astryx `ToolCall` 组件展示检索关键词与返回条数；
- **参考来源展示**：回复尾部或工具结果区展示可点击的来源标题 + 域名摘要（点击通过主进程受控外链打开确认安全后交由系统浏览器打开）；
- **视觉规范**：遵循 `docs/DESIGN.md`，使用语义化 Token（如 `bg-surface`、`text-secondary`、`rounded-lg`），不引入高饱和装饰颜色。

## 7. 分期规划与验收标准

### Phase 1（MVP）
- [ ] 主进程实现 `WebSearchGateway`（至少支持 Tavily + Serper，复用应用代理配置）；
- [ ] 设置页新增联网搜索开关与 Key 校验（测试连通性）；
- [ ] 聊天流注入 `web_search` tool，输入框增加临时开关；
- [ ] 前端正确渲染 `web_search` 工具调用过程与来源链接。

### Phase 2（增强）
- [ ] 增加 `web_fetch` 受限正文抓取；
- [ ] 增加免 Key 备用源（如 SearXNG 自定义端点）；
- [ ] 消息内角标引用 `[1]` 悬停预览来源摘要。

### 验收标准
1. 问剧情前后文时**不会误触发**联网搜索；
2. 问台词典故或显式要求搜索时能稳定返回真实 URL 引用且可点击打开；
3. 断网或 Key 错误时 UI 给出清晰可读反馈，不中断当前整句学习会话；
4. 所有新增 IPC 通道与配置项通过类型检查、契约测试及单元测试。
